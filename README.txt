CareerScope — Step 3

Files:
- dashboard.html: dashboard page structure
- dashboard.css: original black/violet/cyan theme and responsive metric/chart styling
- dashboard.js: guest profile, navigation, metric period selector, and Chart.js visualizations

Run:
1. Keep these files in the same folder.
2. Keep your existing tooplate-2167-orbital-style.css in this folder too (it supplies the background aura/stars theme).
3. Open dashboard.html through your local server or browser.

Chart.js is loaded from jsDelivr, so an internet connection is required for the charts.
The numbers are clearly labelled illustrative demo data; connect a trusted dataset/API before treating them as live statistics.
The logout button expects login.html to exist in the same project folder.
